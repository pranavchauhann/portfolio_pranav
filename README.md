# Portfolio — Pranav Chauhan

Personal portfolio site for Pranav Chauhan — software engineer, businessman, professional photographer, and stock trader.

Built as a static site (HTML/CSS, no build step) and deployable directly, e.g. via GitHub Pages.

## Pages

- `index.html` — Home
- `about.html` — About Me
- `portfolio.html` — Portfolio
- `business.html` — My Business
- `projects.html` — My Projects (GitHub repo cards)

## Structure

- `style.css` — shared site styles
- `images/` — site images

## Running locally

Open `index.html` directly in a browser, or serve the directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
